# XR-learning-experience-for-binary-number-conversion

# Project Idea 
This project will be an XR learning environment where users can practice binary, decimal and hexadecimal conversions.
Users will be able to interact with individual bits and see how them changing one bit effects the whole number. There will be two modes in this project a practice mode and a challenge mode.

# Practice Mode 
The practice mode will show the user 8 bits across the screen and there will be a button underneath each one that will allow the user to change the number from a 1 to a 0 if they are looking at binary or from a 1 to a F if they are doing hexadecimal and so on. I'm not sure whether I will have a 3 sided view with decimal, binary and hexadecimal on each side or if i will just have a menu where the user can choose what one they want to look at.
There will be sounds when they click each button and so on.

# Challenge Mode 
The challenge mode will allow users to test their knowledge which they have gained from the practice mode. Users will be shown a menu which will allow them to choose what number system question they want and then the user will be given a number that they will have to make in that number system. If they get it right they can move onto harder questions or if they get it wrong they can try again.
